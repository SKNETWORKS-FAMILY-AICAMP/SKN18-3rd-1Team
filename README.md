# SKN18-3rd-1Team
보험 약관 PDF 전처리 프로젝트

## 프로젝트 개요
자동차 보험 약관 PDF 파일을 RAG(Retrieval Augmented Generation) 시스템에 활용하기 위해 전처리하는 프로젝트입니다.

## 데이터 구조

### 입력
- PDF 파일: `data/` 폴더 내 보험사별 자동차 보험 약관

### 출력
- CSV 파일: `results/pdftocsv/insurance_clauses.csv`
- 컬럼 구조:
  - **회사명**: 보험사 이름 (KB, 삼성화재, 롯데 등)
  - **보험명**: 보험 상품명 (개인용자동차보험, 업무용자동차보험 등)
  - **조항**: 약관의 계층 구조 (예: 제1편 용어의 정의 > 제1장 배상책임 > 제1조 (보상내용))
  - **내용**: 해당 조항의 실제 내용 (유사도 계산 대상)

## 사용 방법

### 1. 환경 설정
```bash
pip install -r requirements.txt
```

### 2. 전처리 실행
```bash
python preprocess.py
```

## 전처리 로직
1. PDF를 마크다운으로 변환 (pymupdf4llm)
2. 목차 영역 제거
3. 편-장-절-조 계층 구조 파싱
4. 조항별로 데이터 분할
5. 내용 정제 (불필요한 마크다운 기호, 페이지 번호 등 제거)
6. CSV로 저장

## 주요 특징
- **조 단위 분할**: 각 조항을 개별 행으로 분리
- **계층 정보 보존**: 편 > 장 > 절 > 조 경로를 "조항" 컬럼에 저장
- **내용만 임베딩**: "내용" 컬럼만 벡터 임베딩 및 유사도 계산에 사용
- **메타데이터 활용**: 회사명, 보험명, 조항 경로는 필터링 및 컨텍스트에 활용
